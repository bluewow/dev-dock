# .claude 사용 설명서

---

## 1. 처음 시작할 때

| 명령 | 언제 쓰나요? |
|:-----|:------------|
| `/init` | 이미 있는 프로젝트에서 CLAUDE.md를 만들고 싶을 때 |
| `/init new` | 아예 새 프로젝트를 처음부터 만들 때 |

> CLAUDE.md가 없으면 다른 명령이 제대로 작동하지 않습니다. **반드시 먼저 실행하세요.**

---

## 2. 혼자 빠르게 개발할 때 (`/dev`)

```
/dev:build [기능]   구현 계획만 세워줘 (코드 안 건드림)
/dev:go [기능]      바로 구현해줘 (코드 수정함)
```

**추천 흐름:** `/dev:build` → `/dev:go`
**간단한 건:** `/dev:go`만 바로 써도 됩니다

---

## 3. 아이디어 정리할 때 (`/dev:pm`)

```
/dev:pm 로그인 기능 기획해줘
```

Q&A로 아이디어를 정리하고, 1페이지 HTML 기획서를 만들어줍니다.

---

## 4. 팀으로 기획~개발까지 (`/team:product`)

**한 줄 요약:** 자연어로 요구사항을 말하면, AI 팀이 기획 → 디자인 → 개발까지 진행합니다.

### 사용법

```
/team:product 로그인 기능 만들어줘
```

이렇게 말하면 리더가 알아서 판단합니다:

| 이렇게 말하면 | 이렇게 진행됩니다 |
|:------------|:----------------|
| "로그인 기능 만들어줘" | 신규 기능 → 기획 → 디자인 → 승인 대기 |
| "대시보드 UX 개선해줘" | 기존 개선 → Before/After 디자인 → 승인 대기 |
| "로그인 시 500 에러 발생" | 버그 → 분석 → 수정 → 검증 |

### 전체 흐름

```
요구사항 입력
    │
    ▼
리더가 질문 1~3개 (방향 정렬)
    │
    ▼
팀이 기획서(plan.html) + 디자인(design.html) 생성
    │
    ▼
브라우저에서 HTML 파일 열어서 확인
    │
    ├─ "login 승인"              → spec.md 생성 → 바로 개발 시작
    ├─ "login 승인, 단 OO은 2차에서" → 조건 반영한 spec.md → 바로 개발 시작
    └─ "login 반려, OO 추가해줘"   → 피드백 반영하여 바로 재작업 → 다시 리뷰
```

> **승인하면 바로 개발까지 이어집니다.** 별도로 "개발해줘" 명령을 할 필요 없습니다.
> 반려 시에도 피드백이 자동 반영되어 바로 재작업됩니다.

### 독립적으로 개발만 시킬 때

이미 승인된 spec.md가 있는 태스크라면:

```
/team:product login 개발 진행해
```

### 산출물 위치

```
docs/tasks/001-login/
  ├── context.md        리더가 정리한 프로젝트 컨텍스트 (팀 공유용)
  ├── plan.html         기획서 (브라우저에서 확인)
  ├── design.html       디자인 시안 (브라우저에서 확인)
  ├── design-v1.html    반려된 이전 버전 (자동 백업)
  └── spec.md           구현 스펙 (승인 후 생성)
```

### 이력 확인

`docs/history.html`을 브라우저에서 열면 전체 진행 이력을 볼 수 있습니다.

## 폴더 구조

```
프로젝트/
├── CLAUDE.md              프로젝트 컨텍스트 (/init으로 생성)
├── docs/
│   ├── tasks/             태스크별 산출물
│   ├── history.json       이력 데이터
│   └── history.html       이력 뷰 (브라우저)
└── .claude/
    ├── commands/          커맨드 정의
    │   ├── init.md
    │   ├── dev/           build, go, pm
    │   └── team/          product
    ├── agents/            에이전트 정의
    │   └── product-team.md
    └── README.md          ← 이 파일
```
