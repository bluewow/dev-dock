# Plan (계획)

**구현 계획을 체크리스트로 작성합니다.**

## 사전 준비

1. 루트 CLAUDE.md를 읽고 프로젝트 구조, 패턴, 기술 스택 파악
2. CLAUDE.md가 없으면 `/init` 실행 안내 후 중단
3. 멀티 프로젝트인 경우 CLAUDE.md의 Projects 섹션에서 "$ARGUMENTS"가 속한 프로젝트 확인

## 할 일

1. **기존 코드 스캔** — "$ARGUMENTS" 관련 영역의 기존 자산 파악
   - 재사용할 컴포넌트 목록 (경로, variants, props)
   - 스타일 토큰/변수 (globals.css, tailwind config 등)
   - 기존 코딩 패턴 (컴포넌트 구조, 상태 관리, 데이터 페칭)
2. **구현 계획 수립** — CLAUDE.md의 패턴/구조에 맞춰 단계별 작업 순서 정리
3. **변경 사항 정리** — 수정/생성/삭제할 파일 목록
4. **위험 요소 파악** — 예상 문제점, 주의사항

## Rules

- 코드 수정 금지
- 구현 시작 금지
- 계획만 작성
- CLAUDE.md에 정의된 프로젝트 패턴을 따를 것
- **기존 컴포넌트가 있으면 반드시 재사용 계획에 포함**
- **새 컴포넌트 생성 시 기존 패턴과 동일한 구조로 계획**
