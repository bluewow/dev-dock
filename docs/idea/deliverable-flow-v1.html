산출물 단계별 흐름 뷰어

파일 탭을 단계 흐름으로 전환 — 기획 → 디자인 → 스펙 순서로 의미 부여

2026-03-11

Problem

  • • 파일명(design.html, plan.html)만으로는 기획/디자인/스펙 구분이 안 됨
  • • 탭이 단순 파일 목록이라 단계별 맥락이 없음
  • • 어떤 순서로 봐야 하는지 가이드가 없음
  • • 파일 종류별 성격(HTML 산출물 vs MD 스펙)이 시각적으로 구분 안 됨

Target

프로젝트 관리자

태스크 산출물을 단계별로 검토하는 사용자

기획 → 디자인 → 구현 흐름을 한 눈에 파악하고 싶은 사용자

🔄

단계 흐름 네비

파일 탭 → 단계별 아이콘+라벨 흐름으로 전환

Design Direction

단계별 흐름 의미 기반 직관적 네비

각 단계에 고유 컬러를 부여하여 시각적 구분. 기획=Blue, 디자인=Purple, 스펙=Emerald. 기존 phase 색상 체계와 동일.
