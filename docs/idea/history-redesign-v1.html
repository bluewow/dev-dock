Problem

  • • "기획완료 / 디자인완료 / 승인승인 / 개발완료" 칩이 매 카드마다 반복 → 정보 밀도 낮음
  • • 진행 단계는 이미 태스크 카드에 4-pill bar로 표현 중 → 이력에서 중복
  • • 마지막 note가 개발 로그 수준이라 "뭘 왜 바꿨는지" 파악 어려움
  • • 이력이 "작업 기록"이 아닌 "변경 히스토리"로 읽혀야 함
