프로덕트 개요

배경

어떤 일을 진행할 때 진행 상황을 시각적으로 확인하고, TODO를 체계적으로 관리할 수 있는 프로덕트가 필요합니다. 기존 도구들은 기능이 복잡하거나, 진행도 시각화가 직관적이지 않은 경우가 많습니다.

목표

  • 태스크를 빠르게 추가/관리할 수 있는 직관적 인터페이스
  • 전체 진행률을 한눈에 파악할 수 있는 시각화
  • 마일스톤 기반 프로젝트 진행 추적

핵심 기능 (1차 개발 범위)

P0 - 필수

태스크 CRUD

태스크 생성(날짜/제목/상세), 조회, 수정, 삭제. 삭제 시 확인 다이얼로그 포함.

완료 토글

체크박스로 태스크 완료/미완료 전환. 완료 시 취소선 + 투명도 효과.

진행률 시각화

전체 태스크 대비 완료율을 화살표 프로그레스 바로 실시간 표시.

P1 - 중요

마일스톤 표시

프로그레스 바 위에 주요 일정 포인트 표시 (1차에서는 정적).

데이터 영속성

localStorage 기반 데이터 저장. 새로고침 시에도 태스크 유지.

2차 개발
마일스톤 동적 관리 태스크 우선순위 드래그앤드롭 정렬 다크 모드 알림 프로젝트명 커스터마이징

화면 플로우

SPA (단일 대시보드 화면)
1 상단 네비게이션

로고 (TaskFlow) + 알림 아이콘 + 사용자 프로필 아바타

2 프로젝트 진행도 섹션

프로젝트명 + 진행률(%) + 화살표 프로그레스 바 (그라데이션) + 마일스톤 4개

3 태스크 추가 폼
  • - Due Date (date picker, 필수)
  • - Task Title (텍스트, 필수, 100자)
  • - Details (텍스트 영역, 선택, 500자)
  • - Create Task 버튼
4 백로그 리스트
  • - 정렬: 최신순 (기본)
  • - 태스크 카드: 체크박스 + 제목 + 날짜 + 상세 + 삭제
  • - 빈 상태: "No tasks yet" 안내
  • - 삭제: 확인 다이얼로그 후 삭제

데이터 모델

interface Task {
  id: number;         // timestamp 기반 고유 ID
  date: string;       // YYYY-MM-DD (마감일)
  title: string;      // 태스크 제목 (최대 100자)
  body: string;       // 태스크 상세 설명 (최대 500자)
  completed: boolean; // 완료 여부
}

// localStorage key: "taskflow-tasks"
// 저장 형태: JSON.stringify(Task[])

QA 검증 결과

플로우 상태 비고
태스크 생성 OK 폼 입력 -> 리스트에 추가, 역순 정렬
완료 토글 OK 체크박스 -> line-through + opacity
태스크 삭제 개선필요 확인 없이 즉시 삭제 -> 확인 다이얼로그 추가 필요
진행률 업데이트 OK 완료 토글 시 자동 재계산
빈 상태 처리 OK 모든 태스크 삭제 시 안내 표시
데이터 영속성 NG 새로고침 시 초기화 -> localStorage 연동 필수
