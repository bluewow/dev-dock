Project Hub - 디자인 시안

디자이너A (트렌드/모던) + 디자이너B (안정/실용) 통합안

작성일: 2026-03-10
v1 - 초기 시안

디자인 검토 요약

통합 디자인 장점

  • + 노션 스타일의 클린한 카드 레이아웃 - 정보 밀도와 가독성 균형
  • + 기존 TaskFlow의 indigo 컬러 시스템 일관 유지
  • + 프로젝트 상태를 컬러 도트 + 뱃지로 즉시 식별 가능
  • + 산출물 뷰어가 사이드패널 구조라 컨텍스트 전환 최소화
  • + 반응형 대응: 모바일에서도 핵심 기능 사용 가능

통합 시 조율한 사항

  • ~ 디자이너A의 그라데이션 카드 헤더 -> 단색으로 절제 (노션 톤 유지)
  • ~ 디자이너B의 테이블 레이아웃 -> 카드로 변경 (모바일 친화)
  • ~ 사이드바 네비게이션 채택 (A 제안) + 최소폭으로 축소 가능 (B 제안)
  • ~ 뷰어 레이아웃: 슬라이드 오버 패널 (A) + 리사이즈 가능 (B) 결합

최종 통합 방향

레이아웃

좌측 사이드바(접기 가능) + 메인 콘텐츠 영역. 프로젝트 상세에서는 2열 분할(목록 + 뷰어).

인터랙션

카드 호버 시 미세 엘리베이션 + 보더 컬러 변화. 트랜지션 200ms ease. 모달은 백드롭 블러.

정보 계층

프로젝트명(bold) > 상태 뱃지(color) > 경로(muted) > 진행률(bar) > 최근 활동(text)

디자이너A 시안 (트렌드/모던)

현대적 감각. 미세한 그라데이션, 글래스모피즘 힌트, 넉넉한 여백.

디자인 특징

사이드바 네비게이션

고정 사이드바로 페이지 간 전환 없이 네비게이션. 접기(collapse) 가능하여 뷰어 공간 확보.

카드 호버 엘리베이션

호버 시 보더 컬러가 primary로 변하며 미세하게 부상. 클릭 가능성을 시각적으로 암시.

슬라이드 오버 뷰어

산출물 클릭 시 우측에서 슬라이드인 되는 뷰어 패널. 목록과 뷰어를 동시에 볼 수 있음.

채택/미채택 항목

채택 사이드바 네비게이션 구조
채택 카드 호버 인터랙션 (보더 + 섀도우)
채택 슬라이드 오버 뷰어 레이아웃
미채택 카드 헤더 그라데이션 (노션 톤에 맞지 않음)
미채택 글래스모피즘 모달 배경 (단순한 backdrop-blur로 축소)

디자이너B 시안 (안정/실용)

다양한 경험 기반의 안정적 디자인. 명확한 정보 계층, 접근성 우선.

디자인 특징

정보 밀도 최적화

카드에 필요한 정보만 압축. 프로젝트명, 상태, 진행률, 최근 활동 4단계로 구성.

리사이즈 가능한 패널

뷰어와 목록 패널 사이에 드래그 핸들. 사용자가 원하는 비율로 조정 가능.

명확한 상태 시스템

컬러 도트 + 텍스트 뱃지 이중 표시. 색맹 사용자도 상태 구분 가능.

채택/미채택 항목

채택 정보 계층 구조 (4단계 카드 구성)
채택 컬러 도트 + 텍스트 뱃지 이중 상태 표시
채택 사이드바 최소폭 접기 (아이콘만 표시)
부분채택 리사이즈 패널 -> P2로 이관 (1차에서는 고정 비율)
미채택 테이블 기반 프로젝트 목록 (모바일 대응 어려움)
