Devdock UI 개선 - 디자인 시안

디자이너A(트렌드/모던) + 디자이너B(안정/실용) 통합안

개선 사항

  • 시맨틱 컬러 토큰 도입 - Colors.white/black 하드코딩 완전 제거, 테마 일관성 확보
  • 다크 모드 지원 - Slate 계열 기반 부드러운 다크 팔레트, 눈 편안한 대비율
  • 탭 구조 간소화 - 3탭 → 단일 태스크 리스트 + 이력 버튼으로 깔끔
  • 태스크 카드 강화 - 진행 단계 인디케이터, description, 파일 칩 아이콘
  • 이력 HTML 타임라인 - WebView에서 풍부한 시각화, 단계별 색상 구분
  • 영역별 차등 명도 - 사이드바/컨텐츠/뷰어 간 미세한 명도 차이로 깊이감

최종 판정

디자이너A 의견: 다크 모드의 #0F172A(slate-900) 배경은 트렌디하면서도 Indigo 액센트와 잘 어울립니다. 사이드바를 배경보다 약간 더 어둡게 하여 깊이감을 주면 좋겠습니다.

디자이너B 의견: 시맨틱 토큰 접근이 안정적입니다. status 컬러는 라이트/다크 모두에서 동일하게 유지하되 배경 투명도만 조절하는 것이 일관성에 좋습니다.

통합 결론: 두 디자이너 의견을 반영하여, Slate 계열 다크 팔레트 + 영역별 차등 명도 + status 컬러 동일 유지 방향으로 확정합니다.

디자이너A 의견 (트렌드/모던)

  • 다크 모드 명도 전략: 사이드바 #0F172A → 컨텐츠 영역 #0F172A → 카드 #1E293B 순으로 같은 배경에 카드만 밝게 하여 깊이감. 뷰어 영역은 카드와 동일한 #1E293B로 일체감.
  • Status 배지 다크 모드: 배경색을 rgba 투명도 15%로 처리 (예: emerald → rgba(52,211,153,0.15)), 텍스트는 원색의 400 레벨 유지. 라이트와 다크에서 동일한 인식 가능.
  • Progress Indicator: 기획/디자인/승인/개발 4단계를 작은 바(pill) 형태로, 완료된 단계는 emerald-400, 미완료는 slate-200(라이트)/slate-700(다크).
  • 이력 HTML 스타일: Tailwind CDN + Pretendard 내장, 다크/라이트 CSS 변수로 자동 테마 대응. 타임라인 왼쪽 세로선 + 원형 노드.

디자이너B 의견 (안정/실용)

  • 시맨틱 토큰 명명: scaffoldBg, cardBg, sidebarBg, textPrimary, textSecondary, textTertiary, border, borderSubtle 8개면 충분. hoverBg 추가하면 9개.
  • 기존 AppColors 유지: AppColors의 정적 상수는 그대로 두고, AppSemanticColors를 별도 클래스로 추가. 위젯에서 점진적으로 교체.
  • 테마 전환 저장: 로컬 JSON 설정 파일에 themeMode 필드 추가. SharedPreferences 대신 기존 dart:io 패턴 유지.
  • 태스크 카드 description: history.json의 name 필드를 활용. 없으면 slug만 표시.
