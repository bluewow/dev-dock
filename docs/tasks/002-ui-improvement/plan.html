1 개선 개요

현재 문제점

  • FluentThemeData에 typography 색상 미설정 → 기본 black 노출
  • Colors.white 하드코딩 → 다크 모드 전환 불가
  • 산출물 탭과 태스크 탭 기능 중복
  • 이력 탭이 280px 패널 안 텍스트 리스트 → 가독성 낮음
  • 다크 모드 미지원

개선 방향

  • AppColors에 시맨틱 토큰 추가 (surface, onSurface, card 등)
  • 다크 테마용 팔레트 정의 + 라이트/다크 전환 토글
  • 산출물 탭 제거, 태스크 카드에 파일 + 상태 강화
  • 이력 탭 제거, 이력 버튼 → WebView에서 HTML 타임라인 렌더링
  • 전체 위젯에서 하드코딩 색상 → 시맨틱 토큰 교체

7 우선순위

P0 필수 (이번 개선의 핵심)
  • 시맨틱 컬러 토큰 시스템 구축 (AppSemanticColors)
  • 전체 위젯에서 하드코딩 Colors.white/black 제거 → 시맨틱 토큰 교체
  • 다크 테마 팔레트 정의 및 FluentThemeData 확장
  • 테마 전환 토글 (사이드바 하단)
  • 산출물 탭 제거 + 태스크 탭 강화
P1 중요 (사용성 개선)
  • 이력 탭 제거 → 이력 버튼 + WebView HTML 렌더링
  • 이력 HTML 생성 로직 (타임라인 레이아웃)
  • 태스크 카드에 진행 단계 인디케이터 추가
  • 태스크 카드에 description(name) 표시
P2 부가 (완성도)
  • 테마 설정 영속화 (로컬 저장)
  • 이력 HTML 내 필터/검색 기능
  • 이력 HTML 다크 모드 연동
