개선/주의 사항

파일 내용 표시 시 WebView 대신 Text 위젯으로 충분 (md/json은 단순 텍스트)
설치 중 로딩 인디케이터 필요 (파일 복사 시간이 짧더라도)
판정 디자이너A + 디자이너B 통합안 채택
디자이너A의 모던한 토글/카드 UI와 디자이너B의 안정적인 파일 트리 패턴을 결합. 기존 Fluent UI 패턴(ContentDialog, ToggleSwitch, TreeView 느낌)을 최대한 활용하여 이질감 최소화. .claude 섹션은 접기/펼치기 가능한 ExpansionTile 스타일로 좌측 패널 하단에 배치.
